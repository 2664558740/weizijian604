## 技术要点

1. **结构 / 样式 / 行为分离**：HTML 只放结构，样式在 `css/`，脚本在 `js/` 且外部引入。
2. **命名规范**：所有 CSS 类名、id、JS 变量统一以 `wzz_` 开头（姓名首字母）。
3. **注释规范**：HTML 文件头注明作者、建立时间、使用大模型、功能名称；JS 每个函数上方说明其实现的功能。
4. **选项卡可复用**：`wzz_initTabs(容器)` 传入任意带 `data-wzz-tabs` 的容器即可复用，一个页面可放多组。
5. **切换逻辑**：事件委托监听点击 → **先清除所有选项卡的选中状态** → **再设置当前元素的选中状态**。
